# הלמידה של יערה

אתר תרגול סטטי (HTML/CSS/JS בלבד, בלי build), מתאים ל-GitHub Pages.

- `index.html` – דף הבית + חשבון, אנגלית, ספורט, שפה
- `dictation.html` – הכתבה באנגלית
- `worksheet.html` – תרגילי חשבון קבועים לקראת המבחן
- `hall.html` – היכל התהילה (דורש כניסה והזמנה)
- `cats.html` – אלבום החתולים: נקודות, פתיחת חבילות ואיסוף קלפים
- `admin.html` – יצירת קישורי הזמנה וניהול חברים (מנהלת בלבד)

ההתקדמות והמילים נשמרות ב-`localStorage` של הדפדפן.

## כניסה והיכל התהילה

כמו ב-shelf-awareness: **Firebase Authentication (Google)** + **Firestore**, בהזמנה בלבד.
המשחקים פתוחים לכולם; כניסה נדרשת רק כדי להגדיר פרופיל (שם ודמות) ולפרסם תוצאות.
בסוף סיבוב עם שיא אישי חדש מופיע כפתור "פרסום בהיכל התהילה".

```
js/honey.js            הכניסה, הפרופיל והכפתור הצף (נטען בכל עמוד, חושף window.Honey)
js/fb.js               backend של Firebase
js/demo.js             backend מקומי להדגמה (מוסיפים ?demo לכל כתובת)
js/firebase-config.js  הגדרות הפרויקט + מייל המנהלת
firestore.rules        כללי גישה: להדביק בקונסולת Firebase
```

| נתיב ב-Firestore | תוכן | מי קורא / כותב |
|---|---|---|
| `members/{email}` | רשימת המוזמנים | מנהלת; כל אחת קוראת את עצמה |
| `invites/{code}` | קישורי הזמנה חד-פעמיים | מנהלת; מוזמנת מממשת אחד לעצמה |
| `profiles/{uid}` | שם ודמות | חברים קוראים, כל אחת כותבת את שלה |
| `scores/{uid}_{game}` | השיא האישי (`math`, `worksheet`, `dictation`, `quiz`) | חברים קוראים; כל אחת כותבת את שלה, ורק שיפור |

### הקמה חד-פעמית

1. **Firebase**: צרו פרויקט חדש ב-console.firebase.google.com (בלי Analytics).
2. **Authentication** → Sign-in method → הפעילו **Google**. ב-Settings → Authorized domains ודאו ש-`wolfenfeld.github.io` ברשימה.
3. **Firestore Database** → Create database (production mode). בלשונית Rules הדביקו את `firestore.rules` ולחצו Publish.
4. **Project settings** → Your apps → הוסיפו **Web app** והעתיקו את ההגדרות אל `js/firebase-config.js`.
5. דחפו ל-`main`. נכנסים לאתר כמנהלת, ופותחים את `admin.html` ליצירת קישורי הזמנה.

כל עוד ב-`firebase-config.js` כתוב `REPLACE_ME`, הכניסה וההיכל כבויים והאתר עובד כרגיל.

### בדיקה מקומית

```bash
python3 -m http.server 8765
```

ופותחים `http://localhost:8765/hall.html?demo`. מצב ההדגמה שומר הכול בדפדפן ומציג שחקנים לדוגמה.

## כוכבים וקלפי חתולים

- **כוכבים:** ארנק אחד לכל האתר. בחשבון ביער הגשם כל תרגיל שנפתר נותן כוכב והתרגיל מוחלף בחדש (וחדש גם לא חוזר, האתר זוכר את 400 האחרונים). בהכתבה: 2 כוכבים על מילה בלי עזרה, 1 עם עזרה. בבוחן המילים ובתרגילי המבחן לפי תשובות נכונות, ועוד 5 בונוס על סיבוב מושלם.
- **חבילה** עולה 30 כוכבים ונותנת קלף אקראי. הנדירות מסומנת ב-1 עד 5 חתולים (סיכוי: 45% / 27% / 16% / 8% / 4%). אפשר להחזיק עד **3 עותקים** מכל קלף, וקלף שהגיע ל-3 לא יוצא יותר מחבילות.
- 30 קלפים מוגדרים ב-`js/cards.js`, והתמונות ב-`cards/01.png` עד `cards/30.png`. הפרומפט ל-Gemini: `cards/GEMINI_PROMPT.md`.
- **אחסון:** localStorage, ואחרי כניסה של חברה מוזמנת ב-Firestore (`rewards/{uid}`), כך שהאלבום עובד בכל מכשיר.
- **פוסטר:** כשהאלבום שלם נפתח `poster.html`: פוסטר A4 עם כל הקלפים, להורדה כתמונה או להדפסה.

## חברים (`friends.html`)

- **אתגרים:** שולחים לחבר סט של 5 תרגילים (חשבון או הכתבה, אותו `seed` לשניהם). כל תשובה נכונה שווה 3 כוכבים, ועוד 5 על הכול נכון. המשחק עצמו ב-`challenge.html`.
- **החלפות:** מחליפים רק כפולים (מי שנותנת צריכה 2 או 3 עותקים, ומי שמקבלת צריכה לסיים עם 3 לכל היותר). הקלף שהוצע נשמר בצד ("escrow") עד שהחבר עונה. מי ששלחה אוספת את התוצאה בכניסה הבאה.
- ב-Firestore: `challenges/{id}` ו-`trades/{id}`. שתיהן נקראות רק על ידי השולח והנמען. הארנקים (`rewards`) קריאים לכל החברים, כדי לראות כפולים.

## הזמנת חברים

- כל חברה יכולה להזמין: כפתור "👋 הזמנת חברים" (בתפריט הפרופיל ובדף החברים) שולח קישור אישי דרך תפריט השיתוף של הטלפון (וואטסאפ וכו'), או מעתיק אותו.
- הקישור האישי (`invites/f{uid}`) פועל לכל מי שפותח אותו, כמה פעמים שרוצים. מי שנכנס עם Google הופך לחבר ורואה הודעת ברוכים הבאים.
- **הזמנה במייל:** בדף החברים מזינים כתובת Gmail של חבר/ה. הכתובת מתווספת לרשימת המוזמנים (כך שמספיק להיכנס איתה), ונפתח מייל מוכן לשליחה מתוכנת המייל של השולחת, עם הקישור כגיבוי. האתר עצמו לא שולח מיילים (אין שרת בתוכנית החינמית של Firebase).
- **פרופיל:** שם, בית ספר וכיתה (בחירה מ-א׳ עד י״ב). הכותרת בדף הבית ("הלמידה של …") והשורה מעליה מתעדכנות לפי הפרופיל של מי שנכנס/ת, ובהיכל התהילה מופיעים בית הספר והכיתה ליד השם. מי שלא מילא/ה אותם נשאל/ת פעם אחת. למבקרים שלא נכנסו מוצגת ברירת המחדל של האתר.
- **תמונת פרופיל:** התמונה של חשבון Google, נשמרת בפרופיל ומתעדכנת בכל כניסה (רק כתובות של `googleusercontent.com`). בלי תמונה מוצג אימוג'י.
- קישורים חד-פעמיים ורשימת חברים נשארו ב-`admin.html`. ניתן למחוק קישור אישי מ-Firestore אם הוא הודלף.

## אחרי כל שינוי ב-`firestore.rules`

צריך להדביק את הקובץ ב-Firebase console (Firestore Database → Rules) ולפרסם.
